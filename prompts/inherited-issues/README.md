# Board — inherited-issues

**Opened:** 2026-10-12 · **Board:** [`IMPLEMENTATION_STATE.md`](IMPLEMENTATION_STATE.md)

This is a board with no prompts. It holds the open issues in the layer that SecondaryGWKit (SGK)
recorded while the layer was SGK's code, and handed to this repository on 2026-10-12
(`dk-and-rpk-migration` prompt 09, SGK `5943492`). Each entry here is complete: the defect, the
measurement, the impact and the next step, with the package's code cited at this repository's
commits. SGK's entries stay on its boards as the record of the original measurement; nothing here
depends on reading them.

A campaign that fixes one of these issues takes it over: the entry moves to that campaign's
board's §3, and its row moves in [`docs/OPEN_ISSUES.md`](../../docs/OPEN_ISSUES.md), in the same
commit. Nothing else is done here.
